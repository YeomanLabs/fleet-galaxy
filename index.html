    Fleet Galaxy

    An Intune-managed Windows fleet drawn as a galaxy. Each galaxy is a group (a site, ring, model or release) and each star is one device.

    What you're looking at

    • Distance from the core shows how recently the device checked in. Devices silent for a week or more drift past the disc edge into the halo.
    • Color is whatever you pick on the left: compliance, last check-in, Windows release or patch level.
    • Bigger stars need attention.
    • Patch Tuesday replay simulates this month's update rolling through your rings. It's a projection from ring and check-in data, not install history.
