Time machine

Press play on the last 60 days

The desktop app saves a snapshot every day you refresh. Scrub the timeline and watch Patch Tuesday roll through your rings, Windows 10 machines turn into Windows 11 stars, new laptops arrive and retired ones fade out.

No servers. No telemetry. Read-only.

  • Data goes from Microsoft Graph to your computer, and nowhere else. There is no Fleet Galaxy backend.
  • Read-only, delegated permissions. It sees only what your own Intune and Entra roles already allow.
  • You choose the sources. Turn off People or Defender and those permissions are never requested.
  • Tokens are encrypted with Windows DPAPI (Keychain on macOS). Snapshots are plain files you can delete.
  • Nothing to register. It signs in through Microsoft Graph Command Line Tools, Microsoft's own app that's already in your tenant. Prefer your own registration? Five-minute guide.
  • Open source, MIT licensed. Read every line on GitHub.

Questions

Is it free?

Yes. Fleet Galaxy is open source under the MIT license, built by YeomanLabs.

Windows says "Windows protected your PC". Is that expected?

Yes, for now. The installer isn't code-signed yet, so SmartScreen warns on first run. Click More info → Run anyway, or build it yourself from the source.

Which permissions does it ask for?

Only read-only delegated Microsoft Graph permissions, and only for the data sources you switch on. The full list, and what each one is for, is in the permissions table.

What licenses does my tenant need?

Intune for devices. Sign-in activity and MFA details need Entra ID P1, user risk needs P2, and Endpoint Analytics has to be turned on. Anything that isn't available is skipped, and the app tells you why.

Does it work for any tenant? Does it connect to anything else?

It works with any work account and connects only to Microsoft. There's no Fleet Galaxy server and no YeomanLabs app registration: it signs in through Microsoft Graph Command Line Tools, which already exists in your tenant, or through your own registration if you prefer.

How big a fleet can it handle?

It's drawn in a single GPU pass, so tens of thousands of devices stay smooth on a normal laptop. The demo shows 3,500 devices and 3,400 people.
